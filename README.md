# 🚀 Triki-Galáctico

¡Bienvenido a **Triki-Galáctico**! Una versión moderna y espacial del clásico juego de tres en raya (Triki / Tic-Tac-Toe), desarrollada en **Python** utilizando la librería **Pygame** y con soporte de interacción por voz en español.

## 🕹️ Características del Proyecto
* **Interfaz Gráfica con Pygame:** Tablero visual atractivo con temática galáctica y control de audio independiente.
* **Asistencia por Voz (`probar_voces.py`):** Módulo integrado para alertas y lectura de turnos o estados del juego mediante voz sintetizada en español.
* **Estructura Limpia:** Diseñado bajo buenas prácticas de control de versiones con Git, excluyendo entornos virtuales pesados para mayor ligereza.

## 🛠️ Tecnologías Utilizadas
* **Python** 🐍
* **Pygame** (para la interfaz y lógica del juego)
* **Git y GitHub** (para el control de versiones)

## ⚙️ Cómo Ejecutar el Proyecto Localmente

Sigue estos pasos en tu terminal para clonar y ejecutar el juego en tu computadora:

 **Clona el repositorio:**
   ```
   git clone https://github.com/jhonbui/Triki-Galatico.git
   cd Triki-Galatico
   ```
# 1. Crear y activar el entorno virtual
 ``` 
  python -m venv venv
  .\venv\Scripts\Activate
 ```
# 2. Instalar las dependencias
```
pip install pygame
```
# 3. Ejecutar el juego
```
python Juego-triki.py
```
